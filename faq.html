Questions

What people usually ask before they install BLDR.

Does it cost anything?

The app is free and open source. The Coach uses your own Claude API key, so Anthropic bills you directly, roughly 5 to 15 cents for each workout it writes. Everything else works without a key.

What's a Claude API key?

It's a code from Anthropic that lets BLDR use Claude on your account. You create one in the Claude Console, add some credit, and paste it into BLDR's Settings. The install page has the steps.

Is there an iPhone version?

No. BLDR needs an Android phone running Android 8.0 or later.

Why isn't it on the Play Store?

For now BLDR is a direct download. Android asks you to confirm a couple of times when you install it, and the install page shows what to tap.

Do I need an account?

No. Your workouts and history are saved on your phone, so there's nothing to sign up for.

Does it work without internet?

Building and running workouts works offline. The Coach and the demo videos need a connection.

How do I update it?

Download the newest file from the install page and open it. It installs over the old version and keeps your workouts.

Can I change the app?

Yes. The code is on GitHub under the MIT licence. If you publish your own version, give it its own name and icon.
